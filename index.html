      Minimum Underpinning Theory: Purposeful UI Animations

      Balancing visual hierarchy, user guidance, and accessibility without cognitive overload.

      Selecting which UI components to animate is grounded in visual hierarchy, user guidance, and immediate feedback. Subtle scale and color transitions on buttons and service cards confirm interactivity, while animated state updates direct attention to newly added carbon reduction milestones. At the same time, animations remain purposeful, lightweight, and respect @media (prefers-reduced-motion: reduce) so low-end devices and motion-sensitive users experience smooth, accessible navigation.
